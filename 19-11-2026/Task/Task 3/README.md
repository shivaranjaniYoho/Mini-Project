# Five Visualisations

## Project Overview
This project uses Python, Pandas and Matplotlib to create five visualisations from employee data.

## Dataset
The dataset contains employee information including:
- Employee ID
- Name
- Department
- Salary
- Joining Date
- City

## Visualisations
1. Bar Chart – Employees by Department
2. Histogram – Salary Distribution
3. Pie Chart – Employees by City
4. Box Plot – Salary Outliers
5. Scatter Plot – Employee ID vs Salary

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Structure
- `data/` – Employee dataset
- `charts/` – Five chart images
- `five_visualisations.ipynb` – Jupyter Notebook

## How to Run
Open the notebook in Jupyter and run the cells.
